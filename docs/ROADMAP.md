# 分期实施与验收

## V1.0｜出版底座 + 单调性样章

已在初始工程中提供：XeLaTeX 中文规范排版、学生 / 教师双版本、单调性完整样章、10 道独立题、YAML 元数据、自动索引、基础校验及 CI 配置。

验收要求：

- `python tools/validate.py` 成功且无重复 ID、无无效版权状态。
- `python tools/build.py --edition all` 成功，生成两份 PDF。
- 教师版的训练题答案与题号一一对应；学生版不出现训练题详解。
- 数学人工审读后才能将 `draft` 升级为 `math_checked`。
- 抽查每一页 PDF 无字体缺失、截断、交叉引用错误。

## V1.1｜内容标准与知识目录（本次实现）

交付目录、方法、题型体系（11 领域 / 93 主题 / 42 方法 / 50 题型）、正式编辑审核规范、10 道既有题的题型关联以及引用 / 循环依赖自动校验。**目录均为规划条目**，不能把目录条数视为已完成教材内容。

验收要求：

- `python tools/validate_catalog.py` 检查目录结构、引用、别名、依赖无错误。
- `python tools/render_catalog.py --check` 检查文档和机器目录同步。
- `python tools/validate.py` 兼容 V1.0；原有 10 道题 ID 不变、`draft` 状态不变。
- `python -m unittest discover -s tests -v` 通过，包括故意设置错误引用与依赖环的负向测试。
- `python tools/build.py --edition all` 继续得到可编译的学生版与教师版。

**不在 V1.1 宣称完成**：题量扩展、所有知识实体正文、逐条官方课标对应、独立数学审稿或四类 PDF 模板。

## V1.2｜单调性专题深耕

依照 V1.1 标准，将既有单调性样章扩展为完整题型方法讲义，补充 20–40 道精选题，设置母题—变式关系并逐题审校；选择题、填空题与图形题增加样例并验证排版，完成首轮独立数学复核。

## V1.3｜跨章节通用性与排版

以数列或圆锥曲线为第二专题，检查目录复用；将示范例题全部独立入库，支持纯练习册、答案册等四类输出以及 `--topic` / `--difficulty` 选题。

## V2｜题库生产系统

题目检索、组合条件组卷、难度配比、题型配比、题目指纹与近重复人工复核、专题知识关联可视化。

## V3｜交互工作台

浏览器内数学预览、拖拽组卷、题目审核流、持续编辑接口；后台仍以题目结构化文件为唯一真实源。

## 发布前必须明确

课程标准采用的具体版次、开放版权协议、外部题库来源授权、是否商业发布、数学审稿分工与内容审校负责人。
