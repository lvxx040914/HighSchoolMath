> 以下目录由 `catalog/methods.yml` 与 `catalog/archetypes.yml` 自动生成，所有条目均为待逐步编写的编辑规划，不代表已经完成。

## 解题方法库

| 方法 ID | 方法名称 | 适用条件 / 检查要点 | 典型失误 |
|---|---|---|---|
| `MT-LOGIC-PROOF` | 充要条件与逆向论证 | 区分必要与充分，双向分别证明 | 只证明一个方向即宣布等价 |
| `MT-LOGIC-COUNTER` | 反例与边界值验证 | 否定全称命题时给出合法反例 | 样本不满足前提 |
| `MT-SET-REGION` | 集合与区间运算 | 全集、端点及区间开闭一致 | 忽略空集或端点 |
| `MT-INEQ-SIGN` | 因式分解与符号区间 | 讨论根重数与分母禁区 | 两侧符号未核查 |
| `MT-INEQ-PARAM` | 含参数判别式与分界 | 分类穷尽并独立检查临界值 | 分界取等未覆盖 |
| `MT-INEQ-AMGM` | 基本不等式及等号 | 检查非负、定和定积与取等可行性 | 等号条件无法同时成立 |
| `MT-FUN-DIFF` | 定义法比较差值 | x1与x2在同一区间且x1<x2 | 跨定义域不连通区间比较 |
| `MT-FUN-COMPO` | 复合函数单调性 | 内层值域必须落在外层单调区间 | 外层区间不适用 |
| `MT-FUN-PIECE` | 分段讨论及端点拼接 | 分界点函数值与左右性质均核查 | 各段单调就断言整体单调 |
| `MT-FUN-ROOT` | 单调连续与介值数根 | 确认连续性、极限及相应区间单调 | 只有极值未核存在性 |
| `MT-FUN-AUX` | 构造函数与差值归零 | 构造目的明确且定义域合法 | 任意构造后忽略取等 |
| `MT-FUN-TRANSFORM` | 对称、平移与图像变换 | 自变量和函数值变换先后明确 | 图像变换方向颠倒 |
| `MT-CAL-SIGN` | 导数符号与单调性 | 导数判定区间内可导，闭端点连续 | 导数为零就判极值 |
| `MT-CAL-CRITICAL` | 参数临界值分段 | 临界参数、重根和定义域变化单独核查 | 分类遗漏等号 |
| `MT-CAL-ENDPOINT` | 端点与极值综合比较 | 定义域有界端点时先确认连续性 | 只比较内部驻点 |
| `MT-CAL-NECSUF` | 单调参数反推与充分性 | 导数必要条件与严格单调充分性分开证 | 把导数非负直接等同严格递增 |
| `MT-CAL-BOUND` | 参数区间交集与分界 | 对所有自变量的不等式正确量词化 | 交换对任意与存在 |
| `MT-TRI-IDENT` | 三角恒等变换 | 变换前后保证分母不为零 | 约分损失解 |
| `MT-TRI-PHASE` | 三角函数化一角一函数 | 幅值与相位定义正确 | 忽略定义域及周期 |
| `MT-TRI-LAW` | 解三角形与边角对应 | 边角对应且考虑多解 | 正弦定理反解遗漏钝角 |
| `MT-VEC-COORD` | 向量坐标化 | 基底独立且坐标系适配 | 坐标与几何意义不一致 |
| `MT-VEC-DOT` | 数量积与投影 | 数量积公式成立且模不为零时求夹角 | 除以零向量模 |
| `MT-CPLX-MOD` | 复数代数与模几何 | 共轭、模的性质正确 | 把复数当有序实数 |
| `MT-SEQ-REC` | 递推关系化通项 | 初值、非零条件及递推范围齐全 | 得到通解却遗漏初值 |
| `MT-SEQ-SUM` | 错位相减、裂项与分组 | 项数正确、首末项准确 | 移项后边界项漏写 |
| `MT-SEQ-INDUCT` | 数学归纳法 | 基础步与归纳步成立且起始指标正确 | 归纳假设未用于下一步 |
| `MT-SEQ-MONO` | 数列差商比较 | 取比时分母正性先证明 | 正负项混用比值法 |
| `MT-STE-SYN` | 空间位置关系几何判定 | 判定定理前提逐项成立 | 两线平行推出线面平行时遗漏包含 |
| `MT-STE-VECTOR` | 空间向量与法向量 | 选定非零法向量并核查所在平面 | 二面角余弦正负号弄反 |
| `MT-STE-PROJ` | 空间几何体构造辅助垂线 | 垂足、正交投影位置确定 | 将斜线投影长度当实际长度 |
| `MT-ANA-COORD` | 几何条件坐标化 | 设点和轨迹范围不引入赘根 | 平方变形后不验根 |
| `MT-ANA-CONIC` | 圆锥曲线定义与标准方程 | 焦点参数范围与轨迹定义核验 | 标准式符号写反 |
| `MT-ANA-VIETA` | 直线代入与韦达关系 | 检验判别式及二次项系数非零 | 退化成一次方程未分类 |
| `MT-ANA-INVARIANT` | 圆锥曲线定点定值 | 区分恒成立参数域和有效交点 | 求得形式定值却无真实交点 |
| `MT-STA-COUNT` | 分类加法与分步乘法 | 分类互斥且穷尽，分步无重复 | 重复计数或漏计 |
| `MT-STA-EVENT` | 事件分解与条件概率 | 条件概率分母正且事件关系正确 | 独立与互斥混同 |
| `MT-STA-DIST` | 分布列、期望与方差 | 概率非负且总和为一 | 概率漏项或期望错算 |
| `MT-STA-EST` | 统计图表与结论校准 | 说明样本来源与描述统计局限 | 相关性说成因果性 |
| `MT-MOD-MODEL` | 建模假设、量纲与敏感性 | 量纲相容、适用范围明确 | 模型只是代入却声称预测有效 |
| `MT-MOD-VALID` | 模型验证与误差来源 | 区分拟合与预测、内外验证 | 训练效果当独立验证 |
| `MT-EXT-INVARIANT` | 不变量与极端原理 | 状态空间及操作前后不变性确证 | 观察少量例子就宣称不变量 |
| `MT-EXT-CONSTRUCT` | 辅助构造与转化 | 构造对象满足题设且方向可逆 | 构造附加假设未检验 |

### 使用约束

- 方法不能仅列步骤，还要提供数学原理、严格适用条件、失败情形和反例。
- 每类题型要明确母题、可审计的典型变式和不可逆变形；不能用改数字制造虚假题量。
- 每题的 `archetypes` 字段指向这里的题型 ID，`topics` / `methods` 继续使用 V1.0 实体 ID；将来迁移需要显式脚本。
