# HighSchoolMath V1.4｜数学内容预检与题库质量体系

**日期**：2026-10-20。**版本定位**：数学内容的 AI 辅助初步复核与工程质量改进。不是正式的独立人工数学审稿，也不代表数学题目的版权复审已完成。

## 交付内容

- 完成现有 40 道题的逐题预检，分别记录独立运算检查要点、临界条件、难度与源文件 SHA-256 指纹，审阅证据位于 `review/v1_4_audit.yml`。
- 确认并记录 2 个数学命题等价家族：`0007/0014/0028/0038` 与 `0006/0029`；另外标记 7 个非等价但有教学关联的变式，保留全部永久题目 ID。
- 修正 `HSM-FUN-0040` 独立解答对讲义内部“例题 2”的引用，补全导数与根数分析。
- 重新校准 8 道题的编辑难度分级。更改会影响习题册留白高度；不改变题目内容和答案。
- `tools/validate_review.py` 对 40 份记录覆盖、审核状态、数学关系和内容哈希进行检测。`tools/report_review.py --check` 验证机器生成的审稿报告没有漂移。
- `tools/compose.py --avoid-equivalent` 可在自定义组卷时每个数学等价家族只选择一个代表题。该选项默认关闭，旧题单不受影响。
- 保留 V1.3 的四种 XeLaTeX 输出和 macOS 字体回退策略；新增边界数值烟雾测试，辅助核查参数临界值和重根（不代替数学证明）。

## 核心边界

- 题库仍然是 **40 条记录、其中含已识别的重复命题**；不能将其宣传成 40 道相互独立的题型或全部原创高考真题。
- 40 条 `review_status` 全部保持 `draft`；预检通过不能升级为 `math_checked` 或 `published`。
- 当前独立人工审核数量为 **0**，课程标准对齐和来源许可另须复核。
- 本次不删除历史题目、不新增考试真题，也不做统计意义上的难度测量。

## 验收

```bash
python3 -m pip install -r requirements.txt
make check
make build
make pdfcheck
```

阅读 `docs/V1_4_REVIEW_REPORT.md` 中的 40 道题逐项审核说明。后续独立数学审核需由人重新解答后留下姓名/日期/判断依据，才能修改 `review_status`。
