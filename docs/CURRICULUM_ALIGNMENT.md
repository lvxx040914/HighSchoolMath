# 课程标准与内容范围映射说明（V1.1）

本项目采用 **《普通高中数学课程标准（2017 年版 2020 年修订）》** 作为课程定位的主要参考，官方来源：[教育部通知](https://hudong.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html)、[课程教材研究所下载中心](https://www.ictr.edu.cn/download_center/put.html)。

## 必须区分两套目录

- **课程标准正式结构**：必修、选择性必修、选修等学段与课程主题；正式归属必须直接对照相应标准原文核实。
- **HighSchoolMath 编辑目录**：按学科概念与解题方法重组为 11 个领域，是教学编排，不是课程标准的原文转录；跨章节和竞赛作为独立层。

`catalog/knowledge_map.yml` 内的 `track` 是**编辑候选分层**：`core` 代表主线计划，`selective` 代表选必候选，`cross` 代表综合专题，`extension` 代表非高考主线的竞赛拓展。绝不将这些字段直接标注成官方课程要求或某省高考范围。

**当前待办**：逐主题填写准确标准条目、具体教材版本、地区考纲及年份验证。未确认的内容默认 `status: planned`、`alignment_status: needs_unit_level_verification`；不得声称目录已完成逐条课标对齐。

## 高中数学核心素养

编辑与审稿应兼顾数学抽象、逻辑推理、数学建模、直观想象、数学运算、数据分析；不同题型突出主导素养但不机械强贴标签。教学内容必须优先考虑前置知识与读者层级。

## 版本规则

课程标准、教材版本、地区考试范围三者是不同维度。任何题目只在明确来源与适用范围后才能标记年份、卷别或高考适用性。课程标准变更时保留旧目录记录并添加迁移说明，而不是直接覆写已发布版本的题目标签。
