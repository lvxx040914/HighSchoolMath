# 数学内容模板与审稿记录（V1.1）

> 每个模板用于未来正式写作，不代表仓库中规划条目已经完成。正式条目原则上关联机器目录 ID。

## 模板 A｜知识主题

```text
主题 ID：T-XXX-01
对应已落实实体 ID（如有）：K-XXX-...
题目定位、读者、先修：
一、定义（集合、变量、量词、区间、符号）
二、核心性质与定理（条件、结论、证明）
三、等价命题 / 推论（说明变化后的前提）
四、必要反例与错误命题
五、与其他知识点的依赖与应用
六、已审母题 ID 与对应方法 ID
七、课程标准与教材版本核验记录（来源、页码或条款）
```

## 模板 B｜七段式解题方法

```text
方法 ID：MT-...
1. 解决什么问题（目标和常见条件）
2. 核心思想与数学依据（定理条件、等价变形、几何解释）
3. 适用条件 / 不可使用情形
4. 标准考场流程（公式为主、推导最短且完整）
5. 基础母题（HSM-* 与完整规范解答）
6. 本质变式（至少两种，不是只换数字）
7. 综合应用、边界反例、方法比较
```

## 模板 C｜题型母题

```text
题型 ID：A-...
问题原型：给定/求证/求解/定义域
核心知识：T-...
首选方法与替代方法：MT-...
基础母题：HSM-...
变式轴1：参数位置或区间变化
变式轴2：问法变化或方法更换
核心易错与反例：
覆盖状态：planned / in_progress / reviewed
```

## 模板 D｜独立题目审稿单

```text
题目 ID：HSM-...
审核版本与提交 commit：
题干 / 数学符号 / 图形是否可独立理解：
定义域、参数范围、关键条件：
独立重新求解（不能照搬现成解析）：
关键计算复核：
零点、端点、等号、临界参数：
充要性或可逆变形：
是否存在第二种合法解法 / 反例：
来源与转载许可凭据：
题面及答案排版逐页检查：
审稿人 / 日期 / 结论：
可批准状态：draft / math_checked / typeset_checked / published
```

## 模板 E｜专题验收表

- [ ] 专题覆盖计划中明确列出的知识主题，先修关系可追踪。
- [ ] 每项定理假设正确，必要的证明或反例齐全。
- [ ] 每类已实施题型都有母题、典型变式与易错点。
- [ ] 题目 ID 可追溯，没有跨讲义复制粘贴题干与答案。
- [ ] 题目来源、许可、审稿状态与发布权限一致。
- [ ] 学生版/教师版/答案引用编号一一对应。
- [ ] 两套 PDF 可编译，逐页检查图表与公式。
- [ ] 版本范围明确，未把竞赛拓展混作课标必学。
