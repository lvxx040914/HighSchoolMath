## 推荐学习次序

1. 精确定义 → 导数判据（充分与必要） → 分段及复合；
2. 基础证明题 → 单调区间 → 参数充要性 → 恒成立；
3. 不等式构造 → 连续函数的根数 → 综合变式复盘。
