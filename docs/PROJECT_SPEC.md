# HighSchoolMath 项目总体规范（V1.0）

**文件状态**：初始设计稿（2026-10-20）。**目标**：制作兼具高中教材深度、专题方法论与真题训练价值的可维护数学讲义及题库。对象为普通高中学生、教师、高考备考者；竞赛拓展为独立层级，绝不替代普通高中主线。

## 1. 范围与非目标

### 1.1 内容范围

从知识领域组织内容，且记录课标年份与教材版本，不把单一教材目录硬编码为永久结构。规划领域：

1. 集合、常用逻辑用语与数学基础；
2. 函数（性质、基本初等函数、函数模型）；
3. 三角函数与解三角形；
4. 平面向量与复数；
5. 数列与数学归纳；
6. 立体几何与空间向量；
7. 解析几何（直线、圆、圆锥曲线）；
8. 导数及应用；
9. 计数原理、概率与统计；
10. 不等式、数学思想专题与跨章节综合。

具体章节的「必修 / 选择性必修 / 拓展」归属要以所选择的课程标准及教材版本校验并记录 `curriculum_version`；不假定不同地区、不同年份考试范围完全一致。

### 1.2 内容产品

- **概念讲义**：定义、公式、定理、证明、必要条件、常见误区。
- **题型讲义**：问题原型、数学原理、方法条件、例题与变式、统一结论。
- **题库**：一个题目 ID 唯一；支持多知识点、多方法、多场景引用。
- **组卷输出**：学生版（不含训练答案）、教师版（含答案详解）、专题训练册、按条件筛选的试卷。

### 1.3 V1 不做

不做在线判题、账户管理、付费发布、大规模自动抓取题目、未经许可的扫描图识别批量入库。AI 仅可辅助初稿与检查，不得自动将答案标为已审核。

## 2. 知识模型和引用关系

采用四层并保持独立维护：

| 层 | 内容 | 关联主键 |
|---|---|---|
| 知识 `knowledge` | 定义、结论、证明、知识前置条件 | `K-FUN-MONO` |
| 方法 `methods` | 解题原理、使用条件、步骤、失效案例 | `M-DERIV-SIGN` |
| 题库 `questions` | 元数据、题干、提示、解答、插图 | `HSM-FUN-0001` |
| 产品 `lectures` / `config` | 讲义文本、训练题集合、组卷配置 | `monotonicity` |

知识图谱显式记录 `prerequisites` 和 `related`。题目用数组 `topics` / `methods` 连接多个节点。讲义可引用多个题目；题目不依赖讲义的路径与题号。

## 3. 题目和方法标准

- 每道题必须有不变的 ID，不因排序或删改重新编号；若实质性改题，创建新 ID，旧题标记 `superseded_by`。
- 定义严格区分**单调递增**和**严格单调递增**；定理应写出连续性、可导性及区间条件，特别关注端点和参数临界值。
- 数学解答应「最短但完整」：公式为主，逻辑衔接必要即可；不省略关键分类与充要性论证。
- 习题至少标记 `difficulty`（1–5）、`level`（基础 / 提高 / 压轴 / 竞赛拓展）、`type`、`topics`、`methods`。
- 变式题需记录母题 `variant_of`，禁止把同一题的措辞变形当作大量独立新题。

## 4. 来源、版权与合规

必须维护 `source.kind`（`self_written` / `public_domain` / `licensed` / `reference_only`）、`source.citation`、`source.url`（如适用）、`source.permission`、`source.note`。历年高考题可作事实性题源索引，但是否可以全文转载、重排原题与使用原配图需依据实际许可条件确认。

- 未确认再发布权的内容：只保存索引信息，不入出版产物。
- 外部插图和扫描截图禁止默认搬运；优先自制 TikZ / PGFPlots 矢量图。
- 第三方代码依赖遵循其许可证；**本项目整体采用何种开源许可证尚未决定**，不可默认视为可自由复制转载。
- 公共仓库前逐题完成来源追溯及法务/教学用途核验。

## 5. 工程架构与构建

- 内容格式：规范 LaTeX（题干、解析）+ YAML（结构元数据）。
- 排版：XeLaTeX + `ctex` + AMS 数学宏包 + `tcolorbox`；图像优先 TikZ。
- 脚本：Python 3.10+（校验、生成练习索引、编译）。
- CI：GitHub Actions 上验证数据、编译学生版和教师版 PDF，失败则拒绝合并。
- Git：`main` 保持可编译，功能分支通过 PR 合并；发布时打版本标签 `vX.Y.Z`。

## 6. 审核与质量门槛

一题四关：① 元数据/版权检查；② 数学人工复核（重新独立求解、特殊值、边界、充要）；③ TeX 自动构建检查；④ 版式抽查（错行、孤行、图文位置与字号）。

审核状态：`draft → math_checked → typeset_checked → published`；自动测试只能证明字段/构建完整，不等同数学正确。

定义覆盖率统计时分母明确：例如「某专题计划题型的已审覆盖率」，不能直接把题目数视为质量。

## 7. 可维护性规则

- 题目路径只依赖 ID；专章目录承载展示逻辑，不拥有题目实体。
- 复用环境、数学宏集中在 `tex/preamble.tex`；不在单题内定义同名全局宏。
- 源码只用 UTF-8；提交前检查中文标点、公式环境、图题独立性和引用唯一性。
- 变更数学结论的 PR 需要至少一名与原作者不同的复核者（单人试验期需标注未满足）。
- 元数据 Schema 重大修改需留迁移脚本和兼容记录。

## 8. 后续扩展

V2：题目检索、多维度组卷、变式关系、语义查重、可复算验证；V3：网页端预览、可视化组卷、知识图谱与学习记录。任何网页服务层只能消费标准题库数据，不成为唯一事实来源。
