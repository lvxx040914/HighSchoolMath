# V1.2 发布说明：函数单调性专题试验版

**日期**：2026-10-20
**阶段**：内容增强的可编译候选稿，尚未通过独立人工数学审核。

## 范围与实际完成量

- 保留 V1.1 目录：11 个领域、93 个知识主题、42 种方法、50 类题型（仅规划目录）。
- 新增 HSM-FUN-0011 至 HSM-FUN-0034 共 24 道独立题，累计 **34 道**。全部新增题保留 `draft`。
- `worked_ids` 中 4 道新题进入讲义作为带解答的示范母题；30 道进入训练题单，其中原有 10 道＋新增 20 道。
- 讲义增加一阶导数必要条件、严格单调充分性、分段跨点单调性、参数充分必要验证、反例与自绘 PGFPlots 曲线。
- 增加配置、引用和元数据测试，以及编译后 PDF 题目/答案隔离的文本烟雾测试。

## 安全性与已知边界

- **数学审稿状态仍为 `draft`**：自动测试只能发现缺字段、关联错误、部分数学结构和排版错误；不能替代人工重新解题。
- 既有六道 V1.0 手工示范例题仍在讲义正文中；完全迁入独立题库留待 V1.3。
- 课程标准标签目前保留 V1.1 的参考定位，尚未完成逐知识点与教材版本的官方对照。
- 本版仍只生成学生版和教师版，未实现四版本出版和自动组卷。

## 本地验证流程

```bash
python3 -m pip install -r requirements.txt
make check
make build
make pdfcheck
```

输出 `dist/monotonicity_student.pdf` 与 `dist/monotonicity_teacher.pdf`。

## 更新方式

建议在 GitHub `main` 的 V1.1 基线上新建 `feature/v1.2-monotonicity` 分支，先运行 `git apply --check HighSchoolMath_v1.2.patch` 再应用，跑完整测试，通过 CI 后再提交 PR。补丁与包文件名统一 ASCII 英文。
