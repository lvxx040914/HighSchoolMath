# 数学讲义与题目编辑规范

1. **概念精确**：区分单调与严格单调、必要与充分、极值与最值；区间及定义域写全。存在端点、不可导点时须讨论。
2. **定理前提**：一阶导数判定须说明区间内可导；利用连续闭区间端点值时要说明连续性；不可以「导数等于零」直接认定极值。
3. **分类闭合**：参数问题必须覆盖 `a<0`、`a=0`、`a>0` 等分界，列出的情形互斥且穷尽。
4. **规范作答**：数学公式为主，语言只承担推理衔接；例题可有方法点评，但「规范解答」不得写成口语化教程。
5. **难度**：1 识记直接代入；2 单一方法；3 方法选择与一般分类；4 跨知识点或参数分析；5 压轴综合。难度评分仅为编辑初评，不等于统计标定。
6. **题型**：选择题须存正确选项和解析；填空题保留可接受的等价表达；解答题论证完整。多解题可以有 `solutions/alternative.tex`。
7. **排版**：正文首选 11pt；显示公式不滥用 `\displaystyle`；上下标和括号统一；数学图像尽量矢量化，明确范围、坐标单位与关键点。
8. **审题与验证**：基础题可手工代入检查，参数题抽取临界值与随机值检查；符号/数值程序作为辅助，不代替证明。
9. **来源**：引用真题保留省份、年份、卷别、原题号、合法授权状态；未知来源禁止标注“原创”。
10. **语言**：不使用“显然”“容易知道”替代关键推导；不要重复同一结论和冗长技巧点评。

## 固定讲义结构

- 教学目标与知识前置
- 精确定义与核心定理（含证明或证明线索）
- 方法体系（数学原理、适用条件、判定路径）
- 典型题型（例题、规范解答、变式/易错条件）
- 分层训练（题目引用）
- 教师版答案与必要的易错点说明

## 审核清单

- [ ] 题面所需定义域、参数范围无遗漏
- [ ] 公式推导符合运算前提，所有等号/不等号方向正确
- [ ] 所有参数边界与导数零点单独检验
- [ ] 问题结论覆盖题目的全部要求
- [ ] 来源和插图版权字段完整
- [ ] 编译后无裁切、漏字或公式重叠
