# HighSchoolMath 正式编写与审核标准（V1.1）

> **适用对象**：知识点、解题方法、题型母题、独立题目、讲义章节与 PDF 产品。此规范优先于旧 `EDITORIAL_GUIDE.md` 的同名描述；旧文档保留兼容性。**本版首先规范流程，不自动批准已有题目**。

## 1. 目标与明确不做的事

1. 面向普通高中数学与高考复习，兼顾教师备课。竞赛拓展使用独立的 `extension` 轨道，不得代替主线内容。
2. 内容同时回答「命题是什么、为什么成立、何时适用、怎样识别题型、常见错误在哪」。
3. 不追求题目总量、页数或公式数量。没有独立复核的草稿不得称为“精选真题”。
4. 体系采用**知识主题 T → 方法 MT → 题型 A → 题目 HSM → 讲义 PDF** 五层关联，其中 T/MT/A 是 V1.1 规划目录；V1.0 的 `K-*`、`M-*` 保留作为既有内容实体，依赖目录中的别名兼容。
5. 内容必须注明来源，未确认转载许可的外部材料只建立引用索引；参考、改写、OCR、AI 辅助均不能自动获得原创/授权资格。

## 2. 知识主题规范

每一个 `T-*` 知识主题在落实为正式 `K-*` 教学实体时，必须包含：

- **前置知识**：最短必需链及关联主题；不要预设尚未教过的工具。
- **准确的定义**：集合、变量域、量词顺序、逻辑连接词及适用对象。
- **性质与定理**：分别记录必要条件、充分条件、等价命题；假设变化时明确可能失效的结论。
- **证明或证明路线**：高中范围可证明者给规范证明；明显超出范围者注明为何不展开，不得以“显然”代替证明。
- **关键反例**：至少一个常见误用及其违反的具体前提；简单直接结论可例外并说明。
- **知识依赖**：使用 `prerequisites`，不得形成依赖环。
- **范围标记**：课程标准版次、教材版次、课标归属复核状态；竞赛拓展必须独立标记。

**单调性示例**：若说函数严格递增，先声明在区间 `I` 上任意 `x₁<x₂` 有 `f(x₁)<f(x₂)`；若用拉格朗日中值定理，需保证闭段连续、开段可导。`f'(x)>0` 是严格递增的充分条件但不必要；`f'(x)≥0` 仅直接给出非减，证明严格递增须排除常值段。

## 3. 方法库规范

每个方法单元固定七段：

1. **解决的问题**：方法输入与目标，避免泛称“万能套路”。
2. **数学核心原理**：用定理、构造或等价关系说明，而非仅写操作步骤。
3. **适用条件**：明确可导性、正负性、可逆性、连续性及定义域。
4. **标准流程**：写成可用于考场的有限步骤。
5. **基础母题**：有代表性、可独立复核的题干与答案。
6. **变式例题**：优先改变限制、临界值、问法与证明路径，不允许单纯替换数字充量。
7. **综合题与失效反例**：说明能与什么方法联用、在什么情况下失败。

方法的 `conditions` 与 `failure_mode` 在机器目录中必须非空；更完整的证明存储在实际方法实体文件中。

## 4. 题型母题规范

题型 `A-*` 是**数学目标与结构**的分类，不等于具体题干。每个题型需要：

- 问题原型：已知数据、求证/求解目标、参数与定义域。
- 主方法 / 备选方法：明确各方法前提及计算量差异。
- 典型母题：一题对应唯一 `HSM-*`，有完整规范解答。
- 变式轴：至少两种不同的本质变化，如「固定区间 → 参数区间」「求值 → 证明」「无边界 → 临界点入区间」。
- 反例与易错点：不同难度或不同答案应由数学结构支持。
- 题型覆盖率：**已审题型数 / 计划题型数**，不得用草稿数量代替。

## 5. 一道题的最小可发布标准

`questions/HSM-*/` 下至少存在 `metadata.yml`、`stem.tex`、`solution.tex`。允许增设 `hint.tex`、`solutions/alternative.tex`、`figures/`，不得在单题文件里重定义全局 LaTeX 宏。

- **题干**：唯一可解或清楚表述解的范围；符号及单位完整；不能依赖非授权原题图。
- **分析**：讲义可展示思路分析，答案册不强制；分析须解释为何选用方法，不能代替推导。
- **规范解答**：符号为主、文字连接逻辑，写出定理条件、重要等价步骤、参数临界值及必要的反向验证；最终结论用 `\boxed{}`（长结论可合理拆分）。
- **难度**：`difficulty` 1–5 为编辑预估；`level` 记录基础/提高/压轴/竞赛，不把综合度与运算量混为一谈。
- **题型关联**：V1.1 添加可选 `archetypes: [A-...]`，新录入题建议必填；已存在的 10 题已有示例关联。
- **审查状态**：`draft → math_checked → typeset_checked → published`。只有人工独立审题后可升 `math_checked`，机器测试不能替代。
- **来源**：`source.kind / citation / permission` 完整，来源未知不得填 `self_written`。

### 5.1 极易误判的十种情形

1. 定义域不连通却把各段单调性合并为一个整体区间。
2. `f'(x)=0` 就断言存在极值。
3. 使用中值定理但没有开区间可导或端点连续条件。
4. 导数非负就断言严格递增，而没有排除常值区间。
5. 含参分类漏掉 `a=0`、重根、端点被包含等边界。
6. 将必要条件误当充分条件，或由双向结论只证明一边。
7. 做平方、除法、开方或对数变形却不核可逆性与正值。
8. 求最值仅比较驻点，忽略不可导点、端点及开区间是否取到。
9. 极值与水平线相交时，把重根当多个不同实根。
10. 在统计模型中将相关性写成因果性、将拟合优度写成预测保证。

## 6. 固定讲义模板

讲义由以下模块按教学需要形成，适当篇幅可以合并章节但不能丢失要求：

1. 专题封面：课程版本、目标、先修条件、读者层级。
2. 数学基础：定义 → 定理 → 证明 → 性质联系与反例。
3. 解题方法：按方法实体引用，不重复手工维护通用推导。
4. 典型题型：问题原型、方法、母题、变式、规范解答。
5. 分层训练：按题型覆盖和真实难度选题，而非堆题。
6. 专题复盘：易错检查、知识连接、题型索引与后续学习路径。

**输出产品**：学生讲义（示范例题有解答、训练不带答案）；教师讲义（附训练解析）；纯练习册；独立答案册。V1.1 目前只保证前两种 V1.0 既有产品，后两种属于 V1.3 实现目标。

## 7. 排版、图形与数字规范

- 统一 UTF-8、XeLaTeX、`ctex`；数学包与环境只在 `tex/preamble.tex` 中定义。
- 使用规范 AMS 数学环境，等式推导采用 `aligned` / `align*`；注意 `\dfrac` 只在确需放大分式时使用。
- 行间公式不必每行加框。强调最终结论，避免整段高亮。
- 符号约定一致：`\mathbb R`、`\forall`、区间与端点括号准确；统一数学标点与中文间距。
- TikZ / PGFPlots 优先用于原创建模图形；图像应标注坐标单位和关键点，公式与图都要核查正确性。
- 讲义框应允许跨页但不产生标题孤悬；教师解答保持题号与 ID 对应。
- 印刷目标 A4、11pt 为默认；最终 PDF 需人工逐页检查字体、公式裁切、交叉引用、图像超出边界。

## 8. 发布验收与可复现记录

| 门槛 | 手段 | 判定 |
|---|---|---|
| 元数据、来源、ID | `python tools/validate.py` | 无错误 |
| 目录交叉引用与先修依赖 | `python tools/validate_catalog.py` | 无悬空引用、无循环依赖 |
| 目录衍生文档同步 | `python tools/render_catalog.py --check` | 无漂移 |
| 脚本单元测试 | `python -m unittest discover -s tests -v` | 全部通过 |
| 两套 PDF | `python tools/build.py --edition all` | 编译成功且学生/教师版本正确 |
| 数学与版权发布 | 独立人工复核记录 | 不得用测试通过替代 |

**审核记录**：记录审阅人、时间、命题理解、重新独立计算、临界值与反例检查、来源许可核验、版式检查、复核结果。不得凭一个测试脚本将 `draft` 改为 `published`。

## 9. 实施路径

V1.1 交付“目录与标准”，V1.2 才按此标准增加 20–40 道精选题并逐题审校；V1.3 统一示范例题入库、做四种出版模板；V2.0 再实现检索、组卷与自动发布。严禁用未审题量充当版本完成度。
