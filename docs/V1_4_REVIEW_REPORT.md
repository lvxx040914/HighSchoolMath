## 六、发布与后续审核门槛

1. **独立数学人工复核**：由不同于最初编写者的审阅人重新解答，并对参数条件完成正反向证明。
2. **独立来源与版权审查**：目前只记录最初编写声明，不能据此认定对外素材授权完成。
3. **难度实测**：当前 1–5 等级为编辑判断，并非依据学生作答数据校准。
4. **重复母题编排**：保留永久 ID，但正式习题册须决定重复命题是否替换成不同数学本质的题。
